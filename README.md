För att starta appen följ följande steg:
  1. Öppna mappen tddd80-2025-projekt i VS Code
  2. Skapa en .env-fil i mappen tddd80-2025-projekt om den inte existerar. Filen ska innehålla en rad 
     SECRET_KEY = "<valfri sträng>"
  3. Aktivera virutal enviroment i terminalen med kommandot "source myvenv/bin/activate".
  4. Starta servern lokalt med kommandot "python3 app.py"
  5. I VS Code, gå till tddd80-2025-projekt/studygram/lib/main.dart och klicka på "Run"-knappen.
